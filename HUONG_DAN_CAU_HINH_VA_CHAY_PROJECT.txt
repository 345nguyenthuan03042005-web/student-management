HƯỚNG DẪN CẤU HÌNH VÀ CHẠY PROJECT STUDENT_MANAGEMENT
=====================================================

1. Giới thiệu nhanh
-------------------
Project này gồm 2 phần chính:

- Frontend: React + Vite
- Backend: FastAPI
- Database: MySQL

Port mặc định:

- Frontend: http://localhost:3000
- Backend API: http://localhost:8000
- Tài liệu API Swagger: http://localhost:8000/docs


2. Yêu cầu trước khi chạy
-------------------------
Máy cần cài sẵn:

- Node.js 16 trở lên
- npm
- Python 3.8 trở lên
- MySQL 8.0 trở lên

Có thể kiểm tra nhanh bằng các lệnh:

  node --version
  npm --version
  python --version
  mysql --version


3. Cấu trúc thư mục quan trọng
------------------------------

- frontend\
  Chứa giao diện React/Vite

- backend\
  Chứa API FastAPI

- database\schema.sql
  File tạo cấu trúc database

- run-all.ps1
  Script chạy nhanh frontend + backend

- setup.ps1
  Script hỗ trợ cài đặt môi trường trên Windows PowerShell


4. Bước 1 - Tạo database
------------------------
Mở MySQL và import file schema:

  mysql -u root -p < database/schema.sql

Lưu ý:

- Database mặc định là: student_management
- Schema có thể đã kèm dữ liệu mẫu


5. Bước 2 - Cấu hình backend
----------------------------
Di chuyển vào thư mục backend:

  cd backend

Tạo môi trường ảo nếu chưa có:

  python -m venv venv

Kích hoạt môi trường ảo trên Windows PowerShell:

  .\venv\Scripts\Activate.ps1

Cài thư viện:

  pip install -r requirements.txt


6. Tạo file .env cho backend
----------------------------
Trong thư mục backend, tạo file:

  backend\.env

Nội dung mẫu:

  DATABASE_URL=mysql+pymysql://root:matkhau@localhost:3306/student_management
  SECRET_KEY=doi-thanh-chuoi-bi-mat-cua-ban
  ALGORITHM=HS256
  ACCESS_TOKEN_EXPIRE_MINUTES=30
  DEBUG=True
  APP_NAME=Student Management System

Giải thích:

- root: user MySQL của bạn
- matkhau: mật khẩu MySQL của bạn
- student_management: tên database


7. Chạy backend
---------------
Trong thư mục backend, sau khi đã kích hoạt venv:

  python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

Nếu dùng Python trong venv trực tiếp:

  .\venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

Khi backend chạy thành công:

- API gốc: http://localhost:8000
- Swagger: http://localhost:8000/docs


8. Bước 3 - Cấu hình frontend
-----------------------------
Mở terminal khác, di chuyển vào thư mục frontend:

  cd frontend

Cài thư viện:

  npm install

Chạy frontend:

  npm run dev

Sau đó mở:

  http://localhost:3000


9. Proxy frontend -> backend
----------------------------
Frontend đang cấu hình proxy trong file:

  frontend\vite.config.js

Cấu hình hiện tại:

- Gọi /api/... từ frontend
- Tự động chuyển sang backend http://localhost:8000/api/v1/...

Vì vậy:

- Backend phải chạy trước hoặc chạy cùng lúc
- Nếu backend tắt, frontend sẽ báo lỗi proxy như ECONNRESET hoặc 502


10. Chạy nhanh bằng script có sẵn
---------------------------------
Cách 1 - Cài đặt môi trường bằng PowerShell:

  .\setup.ps1

Script này sẽ:

- Kiểm tra Node.js, npm, Python
- Tạo venv backend nếu chưa có
- Cài dependencies backend
- Cài dependencies frontend


Cách 2 - Chạy nhanh frontend + backend:

  .\run-all.ps1

Script này sẽ:

- Mở backend ở cửa sổ PowerShell mới
- Chạy frontend ở cửa sổ hiện tại

Lưu ý:

- Backend yêu cầu phải có sẵn file:
  backend\venv\Scripts\python.exe
- Nếu thiếu, hãy chạy setup trước


11. Tài khoản đăng nhập mặc định
--------------------------------
Tài khoản mẫu thường dùng:

  Username: admin
  Password: admin123

Nếu không đăng nhập được:

- Kiểm tra dữ liệu mẫu trong database
- Kiểm tra file schema.sql đã import thành công chưa


12. Quy trình chạy chuẩn mỗi ngày
---------------------------------
Sau khi đã cài xong từ lần đầu, mỗi lần làm việc chỉ cần:

Terminal 1:

  cd backend
  .\venv\Scripts\Activate.ps1
  python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

Terminal 2:

  cd frontend
  npm run dev

Mở trình duyệt:

  http://localhost:3000


13. Kiểm tra nhanh khi hệ thống không chạy
------------------------------------------
Nếu frontend mở được nhưng không tải dữ liệu:

1. Kiểm tra backend còn chạy không
2. Mở thử:
   http://localhost:8000/docs
3. Nếu không vào được docs:
   backend đang tắt hoặc bị lỗi

Nếu backend lỗi kết nối database:

1. Kiểm tra MySQL đang chạy
2. Kiểm tra DATABASE_URL trong backend\.env
3. Kiểm tra database student_management đã tồn tại chưa


14. Một số lỗi thường gặp
-------------------------
Lỗi 1: npm không chạy trong PowerShell

Triệu chứng:
- Báo lỗi execution policy

Cách xử lý:
- Dùng npm.cmd thay vì npm
Ví dụ:

  npm.cmd run dev
  npm.cmd run build


Lỗi 2: Frontend báo proxy error / ECONNRESET

Nguyên nhân:
- Backend bị tắt
- Backend vừa crash
- Backend chưa khởi động xong

Cách xử lý:
- Restart backend
- Xem log backend để biết lỗi cụ thể


Lỗi 3: Port đã bị chiếm

Backend:

  python -m uvicorn app.main:app --reload --port 8001

Frontend:
- Sửa trong file frontend\vite.config.js nếu cần đổi port


Lỗi 4: Không đăng nhập được

Kiểm tra:

- Database đã import dữ liệu mẫu chưa
- Username/password có đúng không
- Backend có đang kết nối đúng database không


15. Build production
--------------------
Frontend:

  cd frontend
  npm run build

Backend:
- Chạy bằng uvicorn hoặc triển khai qua môi trường production riêng
- Nên đặt:

  DEBUG=False

- Và đổi SECRET_KEY mạnh hơn


16. Gợi ý file nên kiểm tra khi cần sửa cấu hình
------------------------------------------------

- frontend\vite.config.js
  Cấu hình port và proxy frontend

- backend\app\main.py
  Khởi tạo FastAPI, include router

- backend\requirements.txt
  Danh sách thư viện Python

- frontend\package.json
  Danh sách thư viện frontend và script npm

- database\schema.sql
  Cấu trúc database và dữ liệu mẫu


17. Ghi chú thêm
----------------
- Project hiện phát triển theo môi trường local trước
- Khi thêm route/API mới ở backend, nên restart backend để nạp thay đổi sạch
- Khi thấy dữ liệu không hiển thị ở frontend, hãy kiểm tra:
  1. API có chạy không
  2. Database có dữ liệu không
  3. Log terminal backend có báo lỗi không
